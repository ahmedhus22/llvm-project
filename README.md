Simple implementation of llvm backend for risc-v
------------------------------------------------

This is for learning purposes and experimenting.

Goals:
- [ ] Codegen machine code for risc-v to implement simple arithmetic instructions.
- [ ] Instruction Selection DAG optimizations.

Experimental Goals: Test some random strategies in an attempt to utilize risc-v architecture features.

llvm-reduced-risc-v
llvm backend for riscv (minimal riscv)
